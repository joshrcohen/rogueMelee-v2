# rogueMelee

Fresh Melee NTSC-U 1.02 roguelike implementation. Development follows the supplied v6 execution specification. See IMPLEMENTATION_STATUS.md for verified progress; this repository is not yet a playable release.

The input ISO is local and immutable. Retail assets, tool caches, legacy reference checkouts, and generated images are never committed. The legacy project is used only as the pinned borrowed-special behavior reference. Aerial swapping is excluded from v0.1.0.
